# Pure CSS Sidebar Menu

A slide-out sidebar menu built with HTML & CSS only, using the checkbox toggle trick. Features a glass-style panel, Font Awesome icons, and smooth open/close transitions with no JavaScript.

🔗 **Live Demo:** https://muhammaduzairkhalid15.github.io/Pure-CSS-Sidebar-Menu-Uzi-Solutions/
💻 **Repository:** https://github.com/MuhammadUzairKhalid15/Pure-CSS-Sidebar-Menu-Uzi-Solutions

## ✨ Features

- 🍔 Hamburger button that opens the sidebar, close icon to dismiss it
- 🪟 Glass-style translucent panel with a soft glowing border
- ✨ Smooth slide-in transition and hover effects on menu items
- 🔗 Menu with icons: Dashboard, Shortcuts, Overview, Events, About, Services, Feedback
- 📱 Social media icons at the bottom of the panel
- 🚫 No JavaScript used

## 🔧 Built With

- **HTML5**
- **CSS3** – checkbox hack, sibling selectors, transitions
- **Font Awesome** – icons

2. Open `index.html` in your browser, then click the menu icon to open the sidebar.

## 💡 What I Practiced

- The checkbox hack (`input:checked ~ .sidebar`) to toggle UI state without JavaScript
- Sibling selectors (`~`) to control other elements from a hidden checkbox
- `position: fixed` with `left` transitions for a slide-in panel
- Semi-transparent backgrounds and box-shadows for a glass effect
